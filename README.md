# dsh-input-suggest

适用于 DeepSeek Harness（DSH）0.2.0-rc.2 的任务感知型输入建议插件。它结合最近对话和任务进度，用独立辅助模型生成一条可采纳的下一步指令。输入框空闲且草稿为空时，建议以浅色文字显示。

## 安装和使用

```powershell
node tools/desktop-profile.mjs install
```

安装后重启桌面端。也可执行 `dsh plugin --profile <name> add <本包路径>` 安装到其他 profile。执行 `npm run status` 可核对 desktop profile 的包链接、依赖解析与 bundle 状态。

- **采纳**用 Tab 或工具栏按钮将建议写入草稿。草稿可继续编辑，由你决定何时发送。
- **关闭**用 Escape 隐藏当前建议。**重随**用工具栏按钮或 Alt+/ 换一条。
- **设置**在「智能建议」中选择供应商、模型、思考强度、建议模式、风格和隐私策略。

卸载命令为 `node tools/desktop-profile.mjs uninstall`。在 Windows 的 `link:` 安装形态下，插件目录的 `node_modules` junction 负责解析 DSH 提供的依赖，安装脚本会按需建立。

## 建议策略

| 建议模式 | 行为 |
|---|---|
| Predict · 预测 | 推测用户最可能输入的下一句，维持单句。 |
| Next Action · 推进 | 从已确认目标、当前阶段、明确待办或阻碍中选择下一步。 |
| Hybrid · 混合（默认） | 优先贴合用户意图，在有依据时组织推进指令。 |

宿主根据近期消息和结束原因识别探索、规划、执行、阻塞、验收和完成六种阶段。完成且没有明确后续时静默。错误、阻塞和输出触顶时，建议围绕当前阻碍或未完成事项。用户主动取消后停止自动建议。

回合结束和打开旧会话后的空闲补取共用调度器。真人消息和新回合会作废旧建议并取消在途调用。自动路径按会话、回合和有效上下文去重，每个 profile 每分钟至多 12 次模型调用。手动路径每个 profile 每分钟至多 10 次、单会话至多 4 次。重随遇到重复时可再试一次，重试占用手动预算。模型不可用或无合适建议时，输入框保持可用。

## 设置

| 字段 | 默认 | 说明 |
|---|---|---|
| 启用 | 开 | 控制自动建议，手动重随仍可用。 |
| 供应商 / 模型 / 思考深度 | 空 | 模型路由留空时使用会话最近的模型路由。思考深度留空时使用辅助模型默认值。 |
| 采纳快捷键 | Tab | 可在设置中录入组合键。 |
| 建议模式 | 混合 | 预测、推进或混合。 |
| 输出格式 | 单行 | 单行 / 极简指令 / 结构化（目标·步骤·验收）/ 分步执行 / 研究分析 / 自定义结构。与风格预设独立，只决定建议的形状。 |
| 自定义结构说明 | 空 | 仅输出格式选「自定义结构」时生效：告诉模型每行怎么组织。 |
| Agent 配置 | 开 | 允许 Agent 在会话里通过 input_suggest_config 工具直接修改建议策略。 |
| 任务感知 | 开 | 控制本地任务判断和完成后静默。 |
| 任务上下文级别 | 任务摘要 | 「最近对话」只使用最近消息。「任务摘要」加入本地状态。「扩展上下文」可为续接或阻塞任务加入有限的历史用户指令。 |
| 任务记忆时间 | 30 分钟 | 在当前会话内暂存压缩后的任务目标，供「继续按原方案」等指令引用。设为 0 可关闭。 |
| 草稿续写 | 关 | 预留设置，当前版本支持空草稿建议。 |
| 详细度 / 最长字符数 | 标准 / 240 | 预测模式三档上限为 40 / 120 / 240 字符，推进与混合为 60 / 160 / 260，最终以两项设置的较小值为准。 |
| 建议风格预设 | 中性 | 可选极简指令、方案步骤、理论推导、直接改代码或验证复查。 |
| 提示词模板 / 自定义风格 | 空 | 留空使用内置模板，可追加写作偏好。 |
| 注入本地画像 / 采纳示例 / 持续学习 | 开 | 可分别控制提示词注入和本地反馈记录。 |
| 本地推理策略 | 本地网关 | 可选择本地网关或严格本地。 |
| 允许远端端点 | 关 | 仅在本地网关策略下授权使用已知的远端模型地址。 |

风格预设提供措辞、结构和长度偏好。“套用该预设的推荐值”才会修改详细度与字符上限。自定义风格追加到所选预设后。

风格预设共十种：中性、极简指令、方案步骤、理论推导、直接改代码、验证复查、研究深钻（强调假设 / 推导 / 复杂度 / 边界条件）、直接执行（优先让 Agent 修改并交付）、任务续接（沿当前任务推进）、自定义（不用预设指令）。

模板支持 `{{instructions}}`、`{{mode}}`、`{{style}}`、`{{format}}`、`{{memory}}`、`{{examples}}`、`{{language}}`、`{{detail}}`、`{{maxChars}}`、`{{task}}` 和 `{{extended}}`。内置约束会在缺少 `{{instructions}}` 时自动补入。任务和历史文本作为有界对话数据传给模型。

## Agent 自然语言配置

在 DSH 会话里直接对 Agent 说，Agent 会调用 `input_suggest_config` 工具完成结构化修改：

| 你说 | Agent 执行 |
|---|---|
| “把智能建议改成研究型风格” | apply { stylePreset: research-deep-dive }，profile 持久化 |
| “以后建议写得详细一些” | apply { detailLevel: detailed }，profile 持久化 |
| “智能建议统一采用目标、步骤、约束、验收的格式” | apply { outputFormat: structured } |
| “换成直接执行型” | apply { stylePreset: direct-execution } |
| “这一轮先采用研究风格，其他会话不变” | apply { scope: session, stylePreset: research-deep-dive } |
| “查看当前智能建议的完整提示词配置” | inspect |
| “恢复上次的配置” | restore |

作用范围规则：

- **“这一轮”“当前会话”** → 会话级覆盖，只影响目标会话，插件重启后消失。
- **“以后”“默认”“保存”** → profile 持久化，重启后仍有效。
- 用户未指定时默认 profile 持久化。

Agent 只能修改写作策略字段（风格预设、输出格式、详细度、字符数、模式、模板），不能触碰安全语义字段（enabled、allowRemote、localPolicy、模型路由）。设置页与 Agent 写入实时同步。

## 隐私与反馈

- **本地网关**默认只连接已知的 loopback HTTP(S) 端点。网关可继续远程转发。要使用已知远端端点，需要主动打开「允许远端端点」。无法核实地址的路由始终静默。
- **严格本地**要求回环端点和用户确认过的精确供应商与模型匹配，且远端开关无法放宽此策略。选择前请确认该路由的推理和转发均在本机进行。
- 发送给辅助模型的内容经过模式化脱敏与高置信度复检。上下文仅使用真人消息和助手文本，以及按级别选取的精简任务信息。启用画像或示例注入时，这些片段也会随模型请求发送。
- 建议、学习样本、反馈计数和 Token 计量使用独立的 `input_suggest` 存储域。任务摘要只在当前会话内存中保留。插件通过 DSH 的输入框插槽与 API 网关运行，会话日志由宿主维护。
- 曝光来自实际渲染，采纳来自快捷键或按钮。发送统计将输入框的提交 ID 与宿主的真人消息事件匹配，草稿内容不会通过反馈接口上传。编辑比例取最终发送文本与所采纳建议的差异。画像保留聚合偏好与裁剪后的建议样本。
- 设置页同时展示采纳率、采纳后发送率、平均编辑比例、重复率、候选响应时间与每次采纳后发送的 Token 成本。Token 账本覆盖插件发起的辅助调用，包括未生成建议、取消、失败和重试。Token 数以模型返回的用量为准。
